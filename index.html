How to play

  1. Pick your CEFR level with the colored buttons (A1 → C2).
  2. Choose a game tab: Memory, Word Search, Crossword, or the word-guessing game.
  3. Pick a difficulty level (1 easy → 3 challenging). Timers, moves and hints are built in.

For teachers

  • Fully self-contained: each game is one HTML file with no images, audio, fonts or network dependencies — works offline.
  • Easy to share: send the file by email, USB drive, or open it on an interactive whiteboard; also playable from this hosted page.
  • 12 words per CEFR level, each with an emoji icon and a definition clue; difficulty 1–3 adjusts word count and board size.
  • Free for classroom use. Adapt the word lists in the file’s VOCAB object for your own students.
